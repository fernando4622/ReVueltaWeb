# ReVuelta Web — Product Specification

## 1. Product Definition

ReVuelta Web is the public-facing informational website for **ReVuelta**, a Mexican circular-economy project focused on replacing disposable food and beverage packaging with returnable reusable containers.

The project combines:

- reusable physical containers;
- circular logistics;
- QR-based digital identity;
- circulation and return tracking;
- sanitization;
- a future shared network of users, establishments, return points, and operational processes.

The public website must communicate that ReVuelta is **not merely a reusable container and not merely an application**.

It is a **system for circulating shared reusable containers**.

The website will also include **Ask ReVuelta**, an interactive AI assistant powered by Retrieval-Augmented Generation (RAG), allowing visitors to ask questions and receive answers grounded in official project information.

---

## 2. Core User Understanding

A first-time visitor should quickly understand:

- What problem ReVuelta addresses.
- What ReVuelta is.
- How the reusable-container system works.
- Why users do not need to permanently own the containers.
- How containers circulate through the system.
- How QR codes provide each container with a digital identity.
- How returns and sanitization fit into the lifecycle.
- How participating businesses interact with the system.
- Why technology supports the physical model.
- How impact could eventually be measured.
- What an initial pilot is intended to validate.
- What ReVuelta could become in the future.
- How Ask ReVuelta can help visitors explore the project in more depth.

The central message is:

> You do not need to buy or remember to carry your own container. ReVuelta proposes a shared infrastructure of reusable containers that circulate, return, are sanitized, and are used again.

The website should explain this visually rather than relying on long paragraphs.

## 4. Design Philosophy

The website must feel intentionally designed for ReVuelta.

Do not use a generic landing-page formula such as:

```text
Hero
↓
3 cards
↓
4 cards
↓
Testimonials
↓
CTA
```

The page should instead feel like a **continuous visual narrative**.

Circularity should be the core visual language:

- loops;
- paths;
- rotations;
- circular diagrams;
- connected nodes;
- timelines;
- recurring visual elements;
- container trajectories;
- flowing transitions.

The visitor should almost feel the container moving through the system while scrolling.

## 10. How It Works

The full flow:

### 01 — Order
The user receives food or a beverage in a ReVuelta container at a participating establishment.

### 02 — Scan
Each container can have a unique QR-based digital identity.

### 03 — Use
The user uses the container normally.

### 04 — Return
The container is returned through a participating point according to the system rules.

### 05 — Inspect and sanitize
Returned containers enter an inspection and sanitization process.

### 06 — Another cycle
The container returns to inventory and can circulate again.

Do not present this as six identical cards. Use a continuous visual journey.

## 22. UX Goal

A visitor should understand the essential ReVuelta concept within approximately **30 seconds**.

The site should feel:

- serious;
- understandable;
- technologically credible;
- visually distinctive;
- experimental rather than overconfident;
- designed specifically for ReVuelta.

---

## 23. Content Integrity

ReVuelta is still in development.

Use language such as:

- “we are developing”;
- “we propose”;
- “the system is designed to”;
- “the pilot will evaluate”;
- “our current approach”.

For future concepts, use:

- “could”;
- “our vision is”;
- “in a future network”;
- “the system could eventually”.

Never invent:

- customers;
- partnerships;
- users;
- investors;
- pilot results;
- environmental metrics;
- awards;
- establishments;
- testimonials;
- certifications.

If information is unavailable, use a clearly identified placeholder.
